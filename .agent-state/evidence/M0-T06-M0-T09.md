# Evidence — M0-T06 / M0-T09

## Implemented

- Redaction policy and canary checks for exact/base64 secrets, sensitive object
  fields, headers, and URL query values.
- Dependency-free Rust telemetry and evidence types with validation for
  correlation, classification, artifact hashes, duplicate paths, and safe
  repository-relative evidence paths.
- Focused Node and Rust tests.

## Validation

- Security and unit commands are not run because terminal execution is unavailable
  in the current session.

## Security invariant

No production path may log or serialize plaintext secrets or page-sensitive content.
The redactor is a safety boundary for diagnostics; callers still need classified
capture policy and least-privilege storage.
