# Skill: Write a Resumable Handoff

Before context, quota, lease, or environment termination, record task state, branch/worktree, base/head commits, changed paths, decisions, acceptance evidence, commands/results, failures/reproduction, artifacts/hashes, credentials/approvals involved, and the exact next safe action. The receiving agent must verify all repository facts.
