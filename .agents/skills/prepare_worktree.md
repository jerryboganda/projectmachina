# Skill: Prepare Isolated Worktree

Create a task branch/worktree from the recorded base commit, verify clean status, provision the pinned toolchain and task-only secrets/network policy, record environment/image digests, and prove the fast-gate commands can be invoked. Never reuse another task's mutable worktree.
