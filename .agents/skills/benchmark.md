# Skill: Run Reproducible Benchmark

Freeze candidate/comparison versions, hardware, isolation, fidelity, cache/network policy, corpus, waits, timeout/retry/success rules. Report success rate, p50/p95/p99, CPU, memory, cost, crash/retry rate, and native/fallback split; preserve raw artifacts and do not publish a claim.
