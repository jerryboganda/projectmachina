# Skill: Implement a Task

Read the task, direct requirements, ADRs, contracts, security rules, and fast gate. Plan against each acceptance criterion; implement the smallest coherent change within claimed paths; produce typed errors, cancellation, budgets, telemetry, docs, and migration/rollback where relevant. Do not run the exhaustive final suite.
