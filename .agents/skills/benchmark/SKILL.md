# Reproducible benchmark

Freeze and record the candidate digest, comparison versions, hardware, operating system, isolation topology, resource/fidelity policy, network/cache state, corpus, wait conditions, timeouts, retries, and success criteria.

Run sufficient repetitions and report success rate, p50/p95/p99 latency, CPU time, average/peak memory, completed tasks per core-hour, cost per 1,000 successful tasks, crashes, retries, and native/fallback split. Preserve raw event data, profiles, logs, scripts, and environment manifests by content hash.

Do not publish a multiplier from unequal success, fidelity, or isolation. Label vendor figures separately from reproduced measurements.
